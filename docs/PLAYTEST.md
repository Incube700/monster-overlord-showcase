# Playtest Notes

## Checks from r9

| Check | Observed | Test conditions |
| --- | --- | --- |
| First Walker raised | 7.4, 8.6, and 9.1 s | Three local Studio starts, timed from the first step out of the crypt |
| Recruited Walker dealt damage on an attack order | 8.6, 9.4, and 9.9 s | The same starts, using squad commands |
| Throne recruitment | 6.00 s between two recruits | Controlled Studio take with the throne and room in the squad |
| Bone Rift | 28 damage to one target in the checked hit | Server hit event during a Studio combat run |
| Tower assembly | The platform, walls, stairs, and throne assembled in sequence | Fixed-camera Studio test shown in the clip |

The first two timings come from scripted Studio inputs through the game rules. The throne check and spell check were controlled scenarios. Use these observations as baselines for repeatable tests. First-time play, match balance, and device performance require separate runs with players.
